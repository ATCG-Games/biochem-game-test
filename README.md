# 🧬 Game Project for Oral & Written Communication Class of Ege University Computer Engineering 2025-2026

[![Platform](https://img.shields.io/badge/Platform-Web-blue?style=flat-square)](https://github.com/ATCG-Games/biochem-game-test)
[![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20|%20CSS3%20|%20JS-orange?style=flat-square)](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/HTML5)

This game is an immersive, educational Action-RPG designed to teach high-school level biology and chemistry. Players currently take on the role of **Dr. Şükrü**, an experimental scientist who shrinks himself to enter the human body and combat diseases from the inside.

---

## ✨ Current Key Features

### 🫀 Interactive Circulatory Map
*   **Anatomical Accuracy**: Explore a Coronal Cut of the human body.
*   **Graph-Based Traversal**: Navigate using a realistic network of **Veins**.
*   **Organ Discovery**: Visit the Brain, Heart, Lungs, Liver, Stomach, Kidneys, Intestines, and more.

### 🧪 Educational Biochemistry Integration
*   **Real-World Science**: Every organ features detailed tooltips explaining its biochemical function (e.g., ATP generation in the brain, glycogen storage in the liver, HCl production in the stomach).
*   **Visual Learning**: See where blood flows through the body by clicking the organs.

### 🛡️ Nano-Scale Combat
*   **Enter the Microverse**: Dive inside specific organs for action-packed combat levels.
*   **Shoot to Cure**: Use Dr. Şükrü's nano-bubble to fire projectiles at cellular threats.
*   **Progressive Difficulty**: Earn XP, complete stages (includes a final boss in the last stage), and manage your HP as you fight through organic environments.

---

## 🛠️ Technologies Used

*   **HTML5 & Canvas**: Core game logic and the Action-RPG engine.
*   **SVG (Scalable Vector Graphics)**: The interactive, animated human body map.
*   **CSS3**: Modern "Glassmorphism" UI, neon glow filters, and complex animations.
*   **Vanilla JavaScript**: No heavy frameworks. Just pure, high-performance code for smooth animations and graph logic.

## 🚀 Running the Game

### Prerequisites
A modern web browser (Chrome, Firefox, Edge, or Safari).

### Running Locally
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ATCG-Games/biochem-game-test.git
    ```
2.  **Open the game**:
    Simply click and open `index.html`

### Controls
*   **Map View**: Left-click organs to travel. Hover for biochemistry facts.
*   **Combat View**:
    *   `WASD` or `Arrow Keys`: Move Dr. Şükrü.
    *   `Left Click`: Shoot nano-projectiles.
    *   `ESC`: Pause/Resume.

---

## 🎓 Educational Goals

This project aims to make complex biological concepts intuitive and fun:
1.  **Systemic Thinking**: Understanding the body as a connected network rather than isolated parts.
2.  **Biochemical Foundations**: Learning the roles of oxygen, glucose, enzymes, and toxins in human physiology.
3.  **Anatomical Vocabulary**: Familiarizing students with organ positions and the major blood vessels.
